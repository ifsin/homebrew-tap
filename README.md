# homebrew-tap

```bash
brew install ifsin/tap/gameboy
```

## Formulae

| Name       | Description                                                              |
| ---------- | ------------------------------------------------------------------------ |
| gameboy    | Terminal-rendered Game Boy emulator written in Rust, by [raphamorim](https://github.com/raphamorim/gameboy) |
| gameboyadv | Terminal-rendered Game Boy Advance emulator written in Rust, by [michelhe](https://github.com/michelhe/rustboyadvance-ng) (`--skip-bios` and `--rtc` always on) |
